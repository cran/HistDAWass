1. Creating histogram-valued data

library(HistDAWass)

In HistDAWass a histogram is a distributionH object and a data table whose cells are histograms is a MatH object: rows are individuals (or groups) and columns are histogram-valued variables. This vignette shows how to build them.

A single histogram

A histogram is described by its cumulative distribution function (cdf): the bounds of the bins x and the values p of the cdf at the bounds. For example, the histogram

Bin Probability cdf
[1, 2) 0.4 0.4
[2, 3] 0.6 1.0

is created as

d1 <- distributionH(x = c(1, 2, 3), p = c(0, 0.4, 1))
d1
#>           X         p
#> Bin_1 [ 1 ; 2 )       0.4
#> Bin_2 [ 2 ; 3 ]       0.6
#> 
#>  mean =  2.1   std  =  0.568624070307733 
#>

x must be non-decreasing and p must be non-decreasing from 0 to 1. The mean and the standard deviation are computed when the object is created and are stored in the slots m and s:

d1@m
#> [1] 2.1
d1@s
#> [1] 0.5686241

A single value defines an impulse (a degenerate distribution), and a bin with zero probability (an empty bin) gets a tiny weight of 1e-8, to avoid numerical problems:

distributionH(5)@x
#> [1] 5 5
d2 <- distributionH(x = c(0, 1, 2, 4), p = c(0, 0.5, 0.5, 1))
diff(d2@p) # the probabilities of the bins
#> [1] 5e-01 1e-08 5e-01
plot(d1)

From raw data to a histogram

data2hist() builds a histogram from a sample of values. Several algorithms are available for choosing the bins:

set.seed(1)
x <- c(rnorm(300, mean = 10, sd = 2), rnorm(200, mean = 18, sd = 1))

h_base <- data2hist(x, algo = "base")                     # the bins of hist()
h_quan <- data2hist(x, algo = "FixedQuantiles", qua = 10) # 10 equal-probability bins
h_man  <- data2hist(x, algo = "ManualBreaks", breaks = seq(0, 25, by = 2.5))
h_pl   <- data2hist(x, algo = "PolyLine", epsilon = 0.01) # piecewise linear cdf
sapply(list(base = h_base, quantiles = h_quan, manual = h_man, polyline = h_pl),
       function(h) length(h@x) - 1) # number of bins
#>      base quantiles    manual  polyline 
#>         9        10         8        15

The default, algo = "histogram", chooses the bins with the penalised likelihood method of the histogram package: it is accurate but slower for large samples.

plot(h_quan)

plot(h_quan, type = "CDF")

A matrix of histograms

A MatH object is created from a list of distributionH objects, filled by columns (default) or by rows:

ListOfDist <- list(
  distributionH(c(1, 2, 3), c(0, 0.4, 1)),
  distributionH(c(7, 8, 10, 15), c(0, 0.2, 0.7, 1)),
  distributionH(c(9, 11, 20), c(0, 0.5, 1)),
  distributionH(c(2, 5, 8), c(0, 0.3, 1)),
  distributionH(c(8, 10, 15), c(0, 0.75, 1)),
  distributionH(c(20, 22, 24), c(0, 0.12, 1))
)
MyMAT <- MatH(x = ListOfDist, nrows = 3, ncols = 2,
              rownames = c("I1", "I2", "I3"), varnames = c("Var1", "Var2"))
MyMAT
#> a matrix of distributions 
#>  2  variables  3  rows 
#>  each distibution in the cell is represented by the mean and the standard deviation 
#>               Var1                     Var2          
#> I1  [m= 2.1  ,s= 0.56862 ]   [m= 5.6  ,s= 1.6248 ]  
#> I2  [m= 9.75  ,s= 2.0907 ]  [m= 9.875  ,s= 1.7515 ] 
#> I3 [m= 12.75  ,s= 3.3323 ]  [m= 22.76  ,s= 0.86933 ]

From a data frame of raw data

The most common case: a data frame of raw observations and a grouping variable. Each group becomes a row of the MatH, each numeric variable a column. With the iris data, the three species are the individuals:

groups <- levels(iris$Species)
vars <- names(iris)[1:4]
cells <- list()
for (v in vars) {           # the matrix is filled by columns
  for (g in groups) {
    cells <- c(cells, data2hist(iris[iris$Species == g, v],
                                algo = "FixedQuantiles", qua = 5))
  }
}
IRIS <- MatH(x = cells, nrows = length(groups), ncols = length(vars),
             rownames = groups, varnames = vars)
IRIS

Registration

Two histograms with different bins can be expressed on the same cdf values without changing them (registration). This is the basis of all the fast computations of the package and is done automatically by the methods; it can also be done explicitly:

R <- registerMH(MyMAT)
is.registeredMH(MyMAT)
#> [1] FALSE
is.registeredMH(R)
#> [1] TRUE
R@M[[1, 1]]@p
#> [1] 0.00 0.12 0.20 0.30 0.40 0.50 0.70 0.75 1.00
